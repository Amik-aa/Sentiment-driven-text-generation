# Sentiment-driven-text-generation
Generate AI written text with customizable sentiment (positive, negative, or neutral) using GPT2 and NLP techniques
This is a Streamlit based AI text generator that creates content based on user input and a chosen sentiment (positive, negative, or neutral).
It uses GPT-2 for text generation and VADER (NLTK SentimentIntensityAnalyzer) to ensure that the output aligns with the selected sentiment.
Steps:
1. Enter a prompt in the input box (e.g. The day was going great until...)
2. Select the sentiment you want (Positive, Negative, Neutral).
3. Click the "Generate" button.
4. The model will generate text that aligns with the chosen sentiment.
5. If the generated text does not match the sentiment, the system will regenerate it automatically.
